💡 Two-Stack Navigation Rules

1. Visit New Page

Pushes current page to backStack. Resets forwardStack to empty.

2. Go Back

Pushes current page to forwardStack. Pops top URL from backStack.

3. Go Forward

Pushes current page to backStack. Pops top URL from forwardStack.

4. Clear History

Resets top = -1 for both stacks and clears the active page.
